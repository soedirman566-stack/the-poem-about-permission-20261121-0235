# The Poem About Permission

A tiny program that writes one short poem about agency — the power to ask
and to be given — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That creates `out/entry.txt` containing the poem.
